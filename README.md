## 🚀 How to Run the Programs

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the repository:

```bash
cd C-Programming-Practice
```

3. Compile a C program:

```bash
gcc filename.c -o output
```

4. Run the executable:

**Windows:**
```bash
output.exe
```

**Linux:**
```bash
./output
```
